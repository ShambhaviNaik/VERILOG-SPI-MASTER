# VERILOG SPI-MASTER
##  Project Description

This project focuses on the design and simulation of a Configurable SPI Master Controller using Verilog HDL as part of my academic coursework in Electronics and Telecommunication Engineering.

The SPI Master Controller is designed to perform serial data transmission and reception using the SPI communication protocol. It includes support for all four SPI modes using Clock Polarity (CPOL) and Clock Phase (CPHA) configurations.

The design uses a Finite State Machine (FSM) to control data transmission, a clock divider to generate the serial clock (SCLK), and shift registers to handle data transfer through MOSI and MISO lines.

A Verilog testbench is used to simulate the controller with loopback connections and exercise the four SPI mode configurations. The design and simulation are carried out using AMD Vivado Design Suite.

This project provided an opportunity to explore digital design concepts, Verilog HDL, SPI communication and simulation-based verification. AI-assisted coding tools were also used during the learning and implementation process.
